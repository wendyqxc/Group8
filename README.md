# Group8
This is the Github repository for group 8 of the TIL Python Programming course (TIL6022-2025). All necessary information to reproduce our project analysis can be found in the following files:
- "TILprogramming_project_group8.ipynb" contains the final report, analysing all the plots. 
- "End_code.ipynb" contains all the code used for generating the plots in answering the research questions. 
- "kaart_stedelijkheid_simplified_1.ipynb" contains the code for generating the map of the Netherlands 
- Datasets used can be found in the "Data" folder.
- Generated figures are saved in the "Figures" folder.
